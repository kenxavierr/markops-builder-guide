Utility Queries

Quick SQL utilities for status checks, volume review, and deduplication before creating an audience or a target DE.

Query 1 · Status count check
SELECT
  a.Status,
  COUNT(*) AS Cnt
FROM DEName a
WHERE a.Status IN ('Active', 'Cancelled')
GROUP BY a.Status
Query 2 · Campaign-level status volume
SELECT
  a.CampaignCode__c,
  a.Status,
  COUNT(*) AS Cnt
FROM ent.Salesforce_Sample a
WHERE a.CampaignCode__c = '000000123'
  AND a.Status IN ('Active', 'Cancelled')
GROUP BY
  a.CampaignCode__c,
  a.Status
Query 3 · Total record volume by status
SELECT
  a.Status,
  COUNT(*) AS TotalVolume
FROM ent.Salesforce_Sample a
GROUP BY a.Status
ORDER BY TotalVolume DESC
Query 4 · Volume by campaign code
SELECT
  a.CampaignCode__c,
  COUNT(*) AS TotalRecords
FROM ent.Salesforce_Sample a
GROUP BY a.CampaignCode__c
ORDER BY TotalRecords DESC
Query 5 · Deduplicate records and keep the latest row
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM (
  SELECT
    SubscriberKey,
    EmailAddress,
    FirstName,
    Country,
    ROW_NUMBER() OVER (
      PARTITION BY SubscriberKey
      ORDER BY CreatedDate DESC
    ) AS rn
  FROM ent.CustomerMaster
) x
WHERE x.rn = 1

Tip: use these checks before writing a final audience query or a data extension population step.
