Lesson 01

Variables and values

Store reusable data
Initialize an AMPscript variable

Variables store values you want to reuse. The var statement declares them, and set gives them a value.

AMPscript
%%[
  var @firstName, @city, @offerText

  set @firstName = "Sarah"
  set @city = "Singapore"
  set @offerText = "Free Shipping"
]%%
Lesson 02

Data Extension lookups

Bring data into an email
Read a value and reference it in the email

AttributeValue() gets the subscriber key. Lookup() retrieves the first name.

AMPscript
%%[
  var @SubscriberKey, @FirstName

  set @SubscriberKey = AttributeValue("SubscriberKey")
  set @FirstName = Lookup("ENT.CustomerMaster","FirstName","SubscriberKey",@SubscriberKey)
]%%

Hi %%=v(@FirstName)=%%,
Lesson 03

Conditional content

Show the right message
Use IF, ELSEIF, and ELSE

Conditional logic lets you show different content for different customer tiers, countries, or campaign audiences.

AMPscript
%%[
  var @customerTier
  set @customerTier = "Silver"
]%%

%%[ if @customerTier == "Gold" then ]%%
  Gold member pricing is active.
%%[ elseif @customerTier == "Silver" then ]%%
  Silver member pricing is active.
%%[ elseif @customerTier == "Bronze" then ]%%
  Bronze member pricing is active.
%%[ else ]%%
  Standard pricing applies.
%%[ endif ]%%

Lesson 05

SQL foundations

Select and filter audiences
SELECT records from a Data Extension

SELECT chooses fields. FROM identifies the source. WHERE narrows the audience.

SQL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  LastName
FROM ent.CustomerMaster
WHERE IsActive = 1
ORDER BY FirstName ASC
Lesson 06

JOIN and UNION

Combine Data Extensions
JOIN customer and order data

A JOIN connects related records, such as a customer and their orders.

SQL • JOIN
SELECT
  c.SubscriberKey,
  c.EmailAddress,
  c.FirstName,
  o.OrderID,
  o.TotalAmount
FROM ent.CustomerMaster c
LEFT JOIN ent.CustomerOrders o
  ON c.SubscriberKey = o.SubscriberKey
UNION regional audiences

UNION ALL combines rows from two queries. Both queries must return the same number and order of columns.

SQL • UNION ALL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Singapore

UNION ALL

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Malaysia
