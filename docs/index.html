AMPscript / Data Extensions / Multiple rows
Lesson 06
Work with multiple rows
Use LookupRows and RowCount
Display a product list by iterating through matching rows.
AMPscript 
%%[
  var @rows, @row, @i, @name
  set @rows = LookupRows("ENT.ProductCatalog","Category","Apparel")
  for @i = 1 to RowCount(@rows) do
    set @row = Row(@rows,@i)
    set @name = Field(@row,"ProductName")
]%%
  Product: %%=v(@name)=%%<br>
%%[ next @i ]%%

SQL / Data quality / Deduplication
Lesson 13
Keep only the preferred row
Use ROW_NUMBER and PARTITION BY
Keep the latest record per customer before building an audience.
SQL 
SELECT
  SubscriberKey,
  EmailAddress,
  UpdatedDate
FROM (
  SELECT *,
  ROW_NUMBER() OVER (
    PARTITION BY SubscriberKey
    ORDER BY UpdatedDate DESC
  ) AS RowNum
  FROM ent.CustomerMaster
) x
WHERE RowNum = 1

Utility queries

These helper queries are useful for quick QA checks, campaign volume reviews, and deduplicating rows before writing final audience logic.

Query 1 · Status count check
SELECT
  a.Status,
  COUNT(*) AS Cnt
FROM DEName a
WHERE a.Status IN ('Active', 'Cancelled')
GROUP BY a.Status
Query 2 · Campaign status volume
SELECT
  a.CampaignCode__c,
  a.Status,
  COUNT(*) AS Cnt
FROM ent.Salesforce_Sample a
WHERE a.CampaignCode__c = '000000123'
  AND a.Status IN ('Active', 'Cancelled')
GROUP BY
  a.CampaignCode__c,
  a.Status
Query 3 · Total record volume by status
SELECT
  a.Status,
  COUNT(*) AS TotalVolume
FROM ent.Salesforce_Sample a
GROUP BY a.Status
ORDER BY TotalVolume DESC
Query 4 · Volume by campaign code
SELECT
  a.CampaignCode__c,
  COUNT(*) AS TotalRecords
FROM ent.Salesforce_Sample a
GROUP BY a.CampaignCode__c
ORDER BY TotalRecords DESC
Query 5 · Deduplicate records
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM (
  SELECT
    SubscriberKey,
    EmailAddress,
    FirstName,
    Country,
    ROW_NUMBER() OVER (
      PARTITION BY SubscriberKey
      ORDER BY CreatedDate DESC
    ) AS rn
  FROM ent.CustomerMaster
) x
WHERE x.rn = 1
