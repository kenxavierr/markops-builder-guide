Lesson 01

Variables and values

Store reusable data
Initialize an AMPscript variable

Variables store values you want to reuse. var declares them and set gives them a value.

AMPscript
%%[
  var @firstName, @city, @offerText

  set @firstName = "Sarah"
  set @city = "Singapore"
  set @offerText = "Free Shipping"
]%%

Bring data into an email
Read a value and reference it in the email

Lesson 03

Conditional content

Show the right message
Use IF, ELSEIF, and ELSE

Conditional logic lets you show different content for different customer tiers, countries, or campaign audiences.

AMPscript
%%[
  var @customerTier
  set @customerTier = "Silver"
]%%

%%[ if @customerTier == "Gold" then ]%%
  Gold member pricing is active.
%%[ elseif @customerTier == "Silver" then ]%%
  Silver member pricing is active.
%%[ elseif @customerTier == "Bronze" then ]%%
  Bronze member pricing is active.
%%[ else ]%%
  Standard pricing applies.
%%[ endif ]%%

Lesson 05

SQL foundations

Select and filter audiences
SELECT records from a Data Extension

SELECT chooses fields, FROM identifies the source, and WHERE narrows the audience.

SQL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  LastName
FROM ent.CustomerMaster
WHERE IsActive = 1
ORDER BY FirstName ASC
Use multiple filters
SQL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.CustomerMaster
WHERE IsActive = 1
  AND Country = 'Malaysia'
  AND EmailAddress IS NOT NULL

Lesson 06

JOIN and UNION

Combine rows and datasets
JOIN customer and order data

A JOIN connects related data, such as customer records and their orders.

SQL • JOIN
SELECT
  c.SubscriberKey,
  c.EmailAddress,
  c.FirstName,
  o.OrderID,
  o.TotalAmount
FROM ent.CustomerMaster c
LEFT JOIN ent.CustomerOrders o
  ON c.SubscriberKey = o.SubscriberKey
UNION multiple result sets

UNION ALL combines rows from two queries. Both queries need the same number and order of columns.

SQL • UNION ALL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Singapore

UNION ALL

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Malaysia

Dynamic greeting with first name

Personalized offer logic
AMPscript
%%[
  var @customerTier, @offerText

  set @customerTier = Lookup("ENT.CustomerMaster","CustomerTier","SubscriberKey",AttributeValue("SubscriberKey"))

  if @customerTier == "Gold" then
    set @offerText = "Enjoy a 20% Gold member offer."
  elseif @customerTier == "Silver" then
    set @offerText = "Enjoy a 10% Silver member offer."
  else
    set @offerText = "Explore our latest offers."
  endif
]%%

Lesson 08

Best practices

Write cleaner, safer logic
AMPscript best practices
  • Use clear variable names like @firstName instead of @x.
  • Keep logic readable and test in preview before sending.
  • Validate field values and avoid deeply nested conditions when possible.
  • Comment sections when logic gets longer.
SQL best practices
  • Check exact Data Extension field names before running a query.
  • Use WHERE early to reduce data volume.
  • Prefer UNION ALL when duplicates are acceptable.
  • Use aliases and descriptive target names for query clarity.
