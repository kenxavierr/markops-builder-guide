MarkOps Builder Guide

A beginner-friendly guide for marketers and campaign builders using Salesforce Marketing Cloud (SFMC), AMPscript, and SQL.

Use the examples as a practical starter kit for personalization, Data Extension lookups, segmentation, and campaign preparation.

What you will learn

  • How to initialize and reuse AMPscript variables
  • How to pull values from a Data Extension
  • How to personalize email content
  • How to use IF / ELSEIF / ELSE logic and FOR loops
  • How to write basic SQL using SELECT, WHERE, JOIN, and UNION

1. Variable initialization

AMPscript
%%[
  var @firstName, @city, @offerText

  set @firstName = "Sarah"
  set @city = "Singapore"
  set @offerText = "Free Shipping"
]%%

2. Reading values from a Data Extension

AMPscript
%%[
  var @SubscriberKey, @FirstName

  set @SubscriberKey = AttributeValue("SubscriberKey")
  set @FirstName = Lookup("ENT.CustomerMaster","FirstName","SubscriberKey",@SubscriberKey)
]%%

Hi %%=v(@FirstName)=%%,

6. SQL SELECT and filtering

SQL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  LastName
FROM ent.CustomerMaster
WHERE IsActive = 1
ORDER BY FirstName ASC

7. SQL JOIN

SQL
SELECT
  c.SubscriberKey,
  c.EmailAddress,
  c.FirstName,
  o.OrderID,
  o.TotalAmount
FROM ent.CustomerMaster c
LEFT JOIN ent.CustomerOrders o
  ON c.SubscriberKey = o.SubscriberKey

8. SQL UNION

SQL
SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Singapore

UNION ALL

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Malaysia

Best practices

  • Use clear variable names and exact Data Extension field names.
  • Test AMPscript in preview before sending.
  • Filter early in SQL to reduce the audience and query workload.
  • Use UNION ALL when duplicate rows are acceptable.
