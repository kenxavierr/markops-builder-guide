MarkOps Builder Guide

A beginner-friendly guide for marketers and campaign builders using Salesforce Marketing Cloud (SFMC), AMPscript, and SQL.

This repository is designed as a practical starter kit for teams that want strong personalization, clean query logic, and easy-to-copy examples.

What you will learn

  • How to initialize and reuse variables in AMPscript
  • How to pull values from a Data Extension
  • How to personalize email content with Data Extension values
  • How to use IF / ELSEIF / ELSE logic
  • How to build basic FOR loops
  • How to write simple SQL for queries and segmentation
  • How to combine data using JOIN and UNION
  • How to build a clean beginner workflow for campaign work

1. Variable initialization

%%[
  var @firstName, @city, @offerText

  set @firstName = "Sarah"
  set @city = "Singapore"
  set @offerText = "Free Shipping"
]%%

2. Reading values from a Data Extension

%%[
  var @SubscriberKey, @FirstName

  set @SubscriberKey = AttributeValue("SubscriberKey")
  set @FirstName = Lookup("ENT.CustomerMaster","FirstName","SubscriberKey",@SubscriberKey)
]%%

Hi %%=v(@FirstName)=%%,

6. SQL select example

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  LastName
FROM ent.CustomerMaster
WHERE IsActive = 1
ORDER BY FirstName ASC

7. SQL JOIN example

SELECT
  c.SubscriberKey,
  c.EmailAddress,
  c.FirstName,
  o.OrderID,
  o.TotalAmount
FROM ent.CustomerMaster c
LEFT JOIN ent.CustomerOrders o
  ON c.SubscriberKey = o.SubscriberKey

8. SQL UNION example

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Singapore

UNION ALL

SELECT
  SubscriberKey,
  EmailAddress,
  FirstName,
  Country
FROM ent.Customers_Malaysia

Best practices

  • Use clear variable names
  • Test AMPscript in preview before send
  • Check exact Data Extension field names
  • Filter early in SQL
  • Use UNION ALL when duplicates are acceptable
