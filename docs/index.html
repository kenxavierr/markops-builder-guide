AMPscript / Data Extensions / Multiple rows
Lesson 06

Work with multiple rows

Display products or recommendations
Use LookupRows with a loop

LookupRows(), RowCount(), Row(), and Field() work together.

AMPscript 
%%[
  var @rows, @row, @i, @name
  set @rows = LookupRows("ENT.ProductCatalog","Category","Apparel")
  for @i = 1 to RowCount(@rows) do
    set @row = Row(@rows,@i)
    set @name = Field(@row,"ProductName")
]%%
  Product: %%=v(@name)=%%<br>
%%[ next @i ]%%

SQL / Combining data / JOIN
Lesson 10

JOIN related Data Extensions

Connect customer and order data
Use a LEFT JOIN

A LEFT JOIN retains all customers.

SQL • JOIN 
SELECT c.SubscriberKey, c.EmailAddress, o.OrderID, o.TotalAmount
FROM ent.CustomerMaster c
LEFT JOIN ent.CustomerOrders o
  ON c.SubscriberKey = o.SubscriberKey

SQL / Data quality / Deduplication
Lesson 13

Deduplicate audience records

Keep one preferred row
Keep the latest subscriber record
SQL • DEDUPLICATION 
SELECT SubscriberKey, EmailAddress, UpdatedDate
FROM (
  SELECT *, ROW_NUMBER() OVER (
    PARTITION BY SubscriberKey ORDER BY UpdatedDate DESC
  ) AS RowNum
  FROM ent.CustomerMaster
) x
WHERE RowNum = 1

Best practices and launch checklist

Use safer, clearer logic

  • Test AMPscript in preview with known subscriber data.
  • Filter early in SQL and use readable aliases.
  • Use predictable target DE names and document refresh behavior.
